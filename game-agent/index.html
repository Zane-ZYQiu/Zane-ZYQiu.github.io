WHAT WE DO

我们主要做三件事

自我修正闭环

Agent 自己验证、自己修，直到游戏行为正确。

写代码进游戏收反馈定位改代码再验证

专治看代码发现不了的 bug

穿过坚固平台、异常碰撞这类物理错误，代码能跑，只有在游戏里和玩家交互时才暴露。

开源游戏交互基准

建成并开源 100+ 个可复现的 2D/3D 案例，评测 Agent 设计、完善和修复游戏的能力。
